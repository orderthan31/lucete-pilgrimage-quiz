## Motion, reproducibility and artifacts

- **8장 × 7초 = 56초**. 각 장면의 마지막 1.5초에 smoothstep 교차 전환하며 마지막 장면도 첫 장면으로 녹아든다. 첫 장면의 팬·줌 위상은 전체 루프 길이에 대해 주기적이다.
- 일곱 야외 장면과 한 제단부: 숲길 → 건물 외관 → 중앙 성모상 → 단풍 정원 → 햇살 조경 → 성모상 접근로 → 낙엽 잔디밭 → 제단부. 오르간 클로즈업 반복 없음.
- 각 `subject_bbox` 전체가 매 프레임 보존되도록 기존 `scripts/namyang_crop.py`를 사용한다. 추가 줌 1.002–1.022배(최대 2.2%); 불가능한 구도는 거부하고 필요한 경우 줌을 줄인다. 딤·문구는 굽지 않는다.
- Python + Pillow + FFmpeg; 앱 의존성 추가 없음. FFmpeg 인코더 스레드 **2**. H.264 CRF24 medium, yuv420p, 음소거(오디오 스트림 없음), faststart.
- 재현: `python scripts/render-namyang-background.py --ffmpeg /path/to/ffmpeg --evidence-dir /private/evidence/folder`.
- 기하 테스트: `python3 -m unittest discover -s scripts -p 'test_namyang_crop.py' -v`. 렌더러는 모든 실제 합성 프레임(전환의 두 소스 포함)의 피사체 포함 여부도 assert하며 크롭 장부를 출력한다.
- 영상: `/media/namyang-background.mp4`, 1920×1080, 24fps, 56초, 1344프레임; **17,168,286 bytes**, SHA-256 `dc6de1a3f48acf882b3ca4253aa3d8871a7f8e5a53ac3ce11bbff9bef69a2d6a`.
- 포스터: `/media/namyang-poster.webp`, 첫 프레임 1920×1080; **497,704 bytes**, SHA-256 `25cdc003e7cf34b152cd565d1cbf8fbbbb9b296dd6b9f1398e9181b83c2774fe`.
- 사설 검증 증거 디렉터리: `/root/.hermes/cache/scratch/lucete-namyang-eight/` — 원본 선택 패널 장부, 독립 사진 시트, 전체 프레임 크롭 장부, ffprobe, 전체 디코드 framemd5, 실제 디코드 프레임 시트, HTTP 바이트 검증. 최종 앱/프로젝터 시각 검수는 별도다.
