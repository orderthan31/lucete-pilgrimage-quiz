# 루체테 CI 자산

## 현재 사용 자산

- 경로: `public/brand/lucete-profile.png`
- 내용: 파란 계단·십자가, 노란색 부분, 한글 문구 및 LUCETE 글자가 포함된 원형 프로필 CI.
- 출처: 사용자가 직접 제공한 루체테 인스타그램 프로필 화면 캡처.
- 지정 프로필: https://www.instagram.com/lucete.ytyd_youth?vrfl=dXB3b3NjNGdjN3Vk
- 원본 프로필 이미지 직접 조회는 HTTP 429로 실패하여 사용자 제공 캡처를 사용했다.
- 처리: 캡처에서 로고 영역만 추출하고 원 바깥을 투명 처리했다. 원래 문양·글자·색과 원 내부의 흰색 바탕은 유지했다. 스마트폰 UI 전체는 프로젝트에 포함하지 않는다.
- 크기: 565 × 565 px, RGBA PNG. 네 모서리 alpha는 0이다.
- 파생 파일 SHA-256: `5d6dc81b64c07161b1c418f26939a6ed35311235a3fefed2a849030c7ccf51ed`
- 원본 캡처 SHA-256: `f549dab13e4a504816baf095baa8bc20b4594ba2e18ef22f341206dba7301fef`

## 사용 기준과 한계

- 이 파일은 원본 벡터 마스터가 아니라 캡처 기반 파생 이미지다.
- 로고를 임의로 다시 그리거나 추정한 글꼴로 재입력하지 않는다.
- Silver는 화면의 UI 팔레트이며 CI를 회색으로 바꾸라는 뜻이 아니다. 이미지의 원래 색을 보존한다.
- 비율을 유지하고 `object-fit: contain`으로 배치한다. 로고 이미지 자체에 필터나 색상 덮어쓰기를 적용하지 않는다.
- 더 선명한 공식 PNG/SVG가 확보되면 같은 자산 경로와 출처 기록을 함께 교체한다.
- 남양성모성지 동영상 권리는 별도 사항이다. CI를 확보한 것으로 영상 배경 요구가 충족되지는 않는다.
