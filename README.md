# 2026 루체테 성지순례

영통영덕성당 루체테 · 남양성모성지

React / TypeScript / Vite 기반의 퀴즈 웹사이트입니다. 현재는 실행 환경과 기본 대기 화면만 구현한 scaffold 단계입니다. 성인 퀴즈와 성당 상식은 각 20문항을 준비할 예정이며, 문제 콘텐츠 및 진행자 화면은 아직 연결되지 않았습니다.

## 로컬 실행

Node.js 24.14.1 (24.x) 및 npm 11.11.0 환경에서 검증합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://localhost:5176`을 엽니다. 개발 서버는 `0.0.0.0:5176`에 바인딩하고, 해당 포트가 사용 중이면 다른 포트로 바꾸지 않고 실패합니다. 네트워크에 노출되는 개발용 서버이므로 신뢰할 수 있는 환경에서만 실행하세요. 파일 접근 허용 범위는 프로젝트 디렉터리로 제한합니다.

## 검증과 빌드

```sh
npm run typecheck
npm test
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. 현재 테스트는 React 서버 렌더링을 통한 기본 화면 검증이며, 실제 브라우저 상호작용 테스트는 후속 진행 화면 구현 단계에서 추가합니다.

`vercel.json`에는 Vite 빌드 및 SPA의 `/index.html` rewrite 설정이 있습니다. 실제 배포는 수행하지 않았습니다.

## 콘텐츠 및 미디어

- 이 체크포인트에는 문제 데이터가 포함되지 않습니다. 콘텐츠 담당자가 별도로 검증한 문제를 연결합니다.
- 남양성모성지 사진이나 배경 영상은 아직 제공되지 않았습니다. 현재 화면은 이미지 없이 CSS로 구성합니다.
- 추후 직접 촬영했거나 사용 허가를 확인한 원본 사진/영상만 선택적으로 추가합니다. 일반 풍경을 남양성모성지 사진처럼 표시하지 않으며 YouTube 영상을 다운로드하거나 재호스팅하지 않습니다.
- `public/favicon.svg`는 이 프로젝트를 위해 만든 단순한 십자가 아이콘입니다.
